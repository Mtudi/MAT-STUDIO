# MATUDI AI Workspace

Standalone Xi workspace interface with Supabase guest authentication, optional email sign-in, streamed OpenRouter responses through the server-side `/api/chat` endpoint, local conversation history and optional cloud sync. An optional direct Gemini provider is also available. The API and Supabase configuration endpoints currently live in the MAT-STUDIO repository root. Provider secrets remain in Vercel environment variables and must never be placed in browser code.
