About Xi

Xi is a personal AI chat interface built with plain HTML, CSS and JavaScript in a single file. Replies come from the provider you configure; Xi never fabricates answers — if the API fails you will see the error.

Instagram Vision

Analyze a Reel you saved. Save the video to your device first, then upload it here.

Why can't I paste a Reel link?

Instagram does not give apps a video file from a public link. Its official API only returns media owned by an Instagram professional account that has authorized an app, and it needs a Meta app and a server to keep access tokens safe. Scraping breaks the platform rules, so Xi does not do it. Only analyze videos you own or have permission to use.

Your video is uploaded to Google to be analyzed and Google deletes it after 48 hours. Your Gemini key is kept in this browser, so use this only on your own device.
