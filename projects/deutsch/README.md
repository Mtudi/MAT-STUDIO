# MATUDI DEUTSCH

An Arabic-supported German A1 starter path designed for independent daily study.

**Interactive preview:** https://sharable.link/t5cevsdg

## Current branch upgrade
- 8 original learning units: introductions, family, daily life, food, home/city, work/study, hobbies/travel, health/everyday communication.
- 71 vocabulary entries with German examples, English meaning and Arabic meaning.
- Flashcards with interval-based spaced review and a due-only review queue.
- Short listening tasks using browser German text-to-speech, reading comprehension, writing prompts and speaking models.
- Arabic grammar explanations alongside German examples.
- A 60-minute daily study checklist, saved sessions and study streak.
- Local-only progress in the browser; no account or server required.

This is an independent beginner learning aid informed by CEFR A1 communication goals. It is not an official Goethe-Institut course, a complete A1 syllabus or a substitute for a teacher. Browser speech quality depends on an installed German `de-DE` voice. Progress is stored in the current browser/device and is not cloud-synced.

Official practice and reference links are provided in the app footer:
- Goethe-Institut A1 practice materials
- Council of Europe CEFR descriptors
