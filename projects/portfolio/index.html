ABOUT THE STUDIO

Build. Test. Refine.

Not just concepts — working software, with clear boundaries between what is live, what is being tested and what is still an idea.

Curiosity with a practical edge.

MATUDI is an independent maker identity exploring how software can make everyday work more useful, expressive and personal. The projects span AI assistants, music tools, chess study, language learning and creative experiences. The work is shared as it develops, with real limitations stated rather than hidden.

01 · Useful first

Start with a real task and build around it.

02 · Honest status

A preview is a preview; a deployment is not proof of quality.

03 · Privacy by default

Keep local data local and protect server credentials.

04 · Iterate with evidence

Test flows, fix errors and refine the experience.
