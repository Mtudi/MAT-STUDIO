# MATUDI Portfolio

A responsive, standalone portfolio for the MATUDI independent builder identity.

## Content principles

- Six projects are described using features evidenced in their current source or previews.
- Project status labels distinguish development, testing and interactive previews.
- No fabricated client names, metrics, awards, years of experience or professional credentials.
- Links point to the current project preview and MAT-STUDIO source repository.

## Experience

- Editorial responsive layout with dark/light appearance.
- Project filters for AI, music, games, learning and creative work.
- Keyboard-visible focus, accessible filter pressed states and reduced-motion support.
- Theme preference persists locally.

## Verification

Playwright checks project filtering, theme persistence, JavaScript runtime and a 390px mobile viewport.
