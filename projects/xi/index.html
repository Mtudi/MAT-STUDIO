MAT-STUDIO PROJECT 01 · AI
Xi

A personal AI assistant designed to become a calm, capable workspace for thinking, creating, and getting everyday work done.

Project foundation · In progress
Personal by design

A focused assistant shaped around one person's workflows, tools, and preferences.

Online from day one

The project is planned as a web-first experience, accessible across devices.

Free-first approach

Prioritize practical features and efficient use of available free services before adding costs.

Project direction

Xi is being developed as a new, independent project. It is not a continuation of MATUDI AI Workspace.

  • Establish a reliable, simple web foundation.
  • Build the assistant interface and core conversation experience.
  • Add integrations only when they provide a clear practical benefit.
  • Keep credentials secure and avoid exposing private API keys in the browser.
