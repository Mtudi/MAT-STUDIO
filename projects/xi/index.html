THE IDEA

Designed as a personal workspace.

Xi is being developed as a coherent product, not a public model demo. The current build prioritizes the interface, controlled access and a server-side path to AI providers.

01 / EXPERIENCE

A focused workspace

A chat-first environment intended for personal thinking, planning and everyday work.

02 / ENGINE

Modular by design

The browser communicates with a server-side engine bridge instead of exposing provider credentials in the page.

03 / CONTROL

Owner-controlled access

The current app is protected. Public visitors can explore this overview, but the working app is not an open demo.

ACCESS & PRIVACY

A public overview. A private app.

This page explains the project; it does not provide a public AI session or a guest account.

Owner access required

The live Xi app uses an owner access gate and expects server-side environment configuration. Do not share owner passwords, access codes or API tokens.

Credentials stay server-side

Provider and engine credentials belong in server environment variables, never in public HTML or a browser-shipped source file.
