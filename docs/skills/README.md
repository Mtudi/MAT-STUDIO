# MAT-STUDIO Agent Skills

These reusable skill guides are stored as documentation; they are not runtime dependencies or installed executables.

| Skill | Apply when |
|---|---|
| [frontend-ui](frontend-ui/SKILL.md) | Responsive, accessible UI, clear hierarchy, meaningful hover/focus/active states and validation. |
| [web-motion](web-motion/SKILL.md) | Smooth hover, click, expand/collapse, transitions, scroll reveals and reduced-motion behavior. |
| [data-visualization](data-visualization/SKILL.md) | Explain product specs and comparisons with accurate visual encoding, labels and accessible color. |
| [video-background-integration](video-background-integration/SKILL.md) | Only when a cinematic video background is explicitly requested. |

For interactive product comparisons, apply frontend-ui first, data-visualization second, then web-motion. MATUDI PES remains the governing quality standard.

The first three skills are vendored from [SvaraNova/skills](https://github.com/SvaraNova/skills) under MIT. See [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).
