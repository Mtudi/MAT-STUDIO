# MATUDI PES — Changelog

All notable changes to the MATUDI Professional Execution Standard are recorded here.

## 1.0.0 — 2026-11-27
- Established MATUDI PES as the default professional execution framework.
- Added mandatory pre-flight audit and research before implementation.
- Defined design, engineering, motion, accessibility, performance, and QA requirements.
- Added honest test reporting: verified, not verified, and known limitations.
- Added safety rules for destructive, security-sensitive, and paid actions.
- Added continuous-improvement workflow so explicit new standards are incorporated and versioned.
- Required each project to have a project-specific brief and acceptance criteria.
