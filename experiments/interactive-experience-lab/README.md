# MATUDI Interactive Experience Lab

A standalone, dependency-light interaction playground. Open `index.html` in a modern browser or publish this folder as a static site.

Contains 12 interactive prototypes: spotlight, magnetic button, 3D tilt, curtain reveal, parallax layers, kinetic characters, geometric mask, animated navigation, toggle, CSS 3D cube, equalizer feedback, and ambient ripple.

This is an experimental sandbox only. It does not modify the portfolio source.
