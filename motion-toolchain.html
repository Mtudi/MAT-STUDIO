The creative toolchain · v1

Ten tools.
One animation workflow.

Motion Atelier remains the central 3D character editor. These projects extend it with 2D animation, motion graphics, procedural scenes, compositing, particle effects and motion capture. The goal is useful interoperability—not pretending every desktop app is already embedded in the browser.

1Shared local AI bridge foundation
Integration truth: the current Motion Atelier AI Bridge can inspect and edit its own character clips and keyframes. It does not yet control these ten external applications. This page separates working export/import paths from future adapters so no capability is misrepresented.

Manim

Procedural / educational animation
Python renderer

Generate precise explainers, diagrams, equations, camera moves and scripted scenes from Python.

Useful output: MP4, still frames and rendered sequences. Bridge route: generate a scene file, render locally, then import the result as a video/reference asset.
Official docs ↗GitHub ↗

Friction

2D motion graphics
ECMAScript scripts

Create vector and raster motion graphics with keyframes, expressions, effects and reusable scenes.

Useful output: animated SVG, MP4/MOV/WebM and PNG sequences. SVG is the lightest web hand-off, but some effects are not supported by its exporter.
Official docs ↗GitHub ↗

OpenToonz

2D traditional / cut-out animation
Frame pipeline

Produce hand-drawn animation, cleanup, levels, Xsheet timing, cut-out scenes and compositing.

Useful output: PNG/TIFF image sequences and video via FFmpeg. Use numbered image sequences for reliable transfer.
Manual ↗Official GitHub ↗

FreeMoCap

Markerless motion capture
Local REST API

Capture body movement from cameras and process it into motion data for character animation and analysis.

Useful route: processed mocap → Blender scene/export → retarget to the Motion Atelier VRM skeleton. Its local REST API is documented as not yet stable.
Official docs ↗GitHub ↗

Motion Canvas

Code-driven motion design
TypeScript / React-style

Build precise animated scenes from TypeScript generators, with a live editor and timeline-oriented workflow.

Useful output: video through its FFmpeg exporter. Best as a separate motion-graphics renderer that shares project assets and design tokens with the studio.
Official docs ↗GitHub ↗

Synfig

2D vector / cut-out animation
XML project + CLI

Animate vector artwork with bones, interpolation and reusable layers; suitable for character loops and explainer assets.

Useful output: native .sif/.sifz/.sfg projects and rendered image/video formats. Native project format is complex and version-sensitive; rendered sequences are safer for interchange.
Official wiki ↗GitHub ↗

Natron

Node-based compositing / VFX
Python + CLI

Composite rendered layers, key, track, grade and build reusable node-based visual-effects pipelines.

Useful route: render Motion Atelier passes → composite in Natron → export final video or image sequence. Background rendering and Python scripting are documented.
Official docs ↗GitHub ↗

Effekseer

Real-time particle effects
WebGL runtime

Design reusable particles, trails, bursts, magic, impacts and stylized environmental effects for games and 3D scenes.

Useful route: author effect → use the WebGL runtime/compatible export → build a Three.js adapter. This is a dedicated integration task, not a drop-in Three.js import.
Official site ↗Tool docs ↗

Theatre.js

Web-native animation sequencing
JSON project state

Author keyframed animation for web scenes and Three.js objects with a visual sequencing editor.

Useful route: import/export Theatre project-state JSON and map supported object properties to the Three.js scene. Strong candidate for the first browser-native timeline adapter.
Official docs ↗GitHub ↗

Pencil2D

Hand-drawn 2D animation
Image-sequence hand-off

Sketch frame-by-frame animation and rough storyboards with a lightweight, approachable drawing workflow.

Useful output: transparent PNG image sequences where supported. Prefer sequences over lossy video when moving animation between tools.
Official docs ↗GitHub ↗

How they fit together

Use Motion Atelier for the 3D character, rig, pose and animation timeline. Route each specialist task to the tool that does it best, then return through explicit, testable interchange formats.

01 · CreateMotion Atelier, Theatre.js, Motion Canvas or Manim author the scene, timing or procedural motion.
02 · Capture / drawFreeMoCap captures movement; OpenToonz, Synfig and Pencil2D create 2D animation.
03 · EffectsFriction creates vector motion graphics; Effekseer authors real-time particles; Natron composites passes.
04 · ExchangePrefer JSON for structured timeline data, VRM/GLB for 3D assets, SVG for vector motion, and PNG sequences for frame-based work.
05 · DeliverRender a final MP4/WebM or transparent image sequence. Keep source projects and export settings alongside the result.
